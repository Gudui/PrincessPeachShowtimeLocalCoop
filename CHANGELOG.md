# Changelog

All notable changes to the public Princess Peach Showtime Local Co-op mod will be documented here.

## v0.1.0-alpha.1

### Initial Alpha Release

- Added native 2-player local co-op on a single shared screen for Princess Peach: Showtime! (version 1.0.0, Title ID `01007A3009184000`).
- Added full Player 2 entity lifecycle with independent controller routing, full physics, jumping, and character movement.
- Added dynamic shared camera that frames both players and widens dynamically as players separate.
- Added separate health tracking and damage isolation with independent UI gauge presentation.
- Added partner recovery and rejoin catch-up leash, bringing Player 2 back when separated.
- Added configurable Player 2 visual appearance (cyan emissive tint) and LayeredFS `settings.ini`.
- Added automated installer supporting both Ryujinx emulator and Atmosphere on physical hardware.
